Aris (studio) as your Agent

A senior-dev workflow you can see and steer — board + chat, on your machine, reachable from phone when you’re away.

Product of madebyaris.com
Contact arissetia.m@gmail.com aris@madebyaris.com

Why this exists

Coding agents are powerful. The process is still invisible.

We built Aris so working with an agent feels like pairing with a senior engineer — not watching a black box dump code.

Why

Continue living products

Software never finishes. You need a workspace that resumes the same folder, board, notes, and chat — session after session.

Pain

What breaks today

  • Chat-only — jumps to code; hides research, plan, proof.
  • Kanban alone — tracks work but can’t run or interrupt an agent.
  • Terminal agents — expert power, weak context for founders/PMs.
  • Cloud-only control — hard when you want local files, secrets, offline nodes.
Solution

Aris (studio)

Board that runs research → plan → build → review, plus immediate chat. One project = one folder. Local node holds secrets; Master/Child agents; phone via Zero Trust when away.

Product stance

The node is the brain. The edge is the door.

Cloudflare and Hermes never hold your secrets or run your agents. Execution, folders, and history stay on your machine — Mac today, Win11 workstation later.

Hostname example: https://agent.madebyaris.com · ADR 012

Agents

Two separate agents

Master

Control plane

Projects, MCP, accounts, memory promote, active node, status. Taskbar center button. Studio-scoped tools.

Child

Project execution

Board phases, project chat, repo cwd, project MCP. One Child per project. Never mutates global registries.

Hermes is an external commander — it can drive Master and project/Child via the Command API (with projectId). No raw SDK. No secrets.

Security

Defense in depth

Data & history

Decentralized: node-local SoT

No central cloud database. Each node works independently. Cloudflare is transport only. ADR 013.

Travels

Project-bound

.aris-workspace/ — tasks, chat.jsonl, specs. Moves with git / open-on-other-node.

Optional sync

Node registry

~/.aris/ → SQLite over time. Settings, MCP meta, Master memory, audit, devices.

Never sync

Secrets

~/aris-secrets — Cursor keys, SSH, MCP tokens. Stay on the node.

Phone / Hermes see history of the active always-on node — not a shared SaaS database.

Away from desk
