# Aris Studio — Architecture presentation

Interactive HTML slide deck (keyboard + touch).

## Open

```bash
open docs/presentations/aris-architecture/index.html
```

Or serve locally:

```bash
pnpm --filter web exec -- serve ../docs/presentations/aris-architecture
```

File: [`index.html`](./index.html)

## Controls

| Input | Action |
|-------|--------|
| `←` `→` / Space | Prev / next |
| `F` | Fullscreen |
| Sidebar / dots | Jump to slide |
| Swipe | Mobile |
